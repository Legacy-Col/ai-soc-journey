#This is a scope of the project which will contain the rules of enganegment

## Authorized targets
Only systems explicitly included in the assessment.

## Prohibited
You will not:
- attack public systems
- attack real organizations
- perform denial-of-service
- destroy data
- steal real credentials
- deploy real malware
- attack systems outside our lab

  
## Allowed
Within our isolated lab:
- reconnaissance
- service enumeration
- vulnerability scanning
- controlled exploitation
- credential/security testing using lab accounts
- privilege escalation demonstrations
- configuration assessment
- network analysis
- evidence collection
