## Query 001 — Baseline Process Creation

### Objective

Identify process creation activity currently being generated by the
Windows endpoint.

### SPL

```spl
index=main sourcetype="XmlWinEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1
| table _time host User Image ParentImage CommandLine ProcessId ParentProcessId
| sort - _time

```

### Process Analysis
This querry was used when I wanted to analys one of the events

index=main source=XmlEventLog:Microsoft-Windows-Sysmon/Operational" EventCode=1 ParentImage="C:\\Windows\\explorer.exe"
